# CodeAlpha Tasks

This repository contains the projects completed as part of the **CodeAlpha Full Stack Development Internship**.

The projects demonstrate practical implementation of frontend development, backend development, database integration, authentication, and REST APIs.

---

## 📌 Projects

### 1. E-Commerce Website

A full-stack e-commerce web application designed to provide users with a simple and convenient online shopping experience.

#### Features
- User registration and login
- Product listings
- Product search
- Category-based filtering
- Shopping cart
- Checkout and order processing
- Order management
- Database integration
- Authentication and authorization

#### Technologies Used
- HTML
- CSS
- Bootstrap
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt

📁 **Project:** [Project-1-E-Commerce-Website](./Project-1-E-Commerce-Website)

---

### 2. Mini Social Media App

A student-focused social media web application that allows users to connect, share updates, and interact with other members of the community.

#### Features
- User registration and login
- Community feed
- Create posts
- Like and unlike posts
- Comments
- Search students
- Follow and unfollow users
- User profiles
- REST API integration

#### Technologies Used
- HTML
- CSS
- Bootstrap
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt

📁 **Project:** [Project-2-Mini-Social-Media-App](./Project-2-Mini-Social-Media-App)
